# awake-watch

Mac が今スリープするかを見張るアプリです。macOS 26 以降。

- スリープしない状態（🔴 フタを閉じても起きてる / 🟡 放っておいても寝ない）になったら通知します。30 分続いたらもう一度知らせます
- コントロールセンターのトグルで「フタを閉じても起きておく」を切り替えられます。**選んだ時間（1・2・4・8 時間、最初は 4 時間）で自動的に元に戻ります**。無期限も選べます
- デスクトップウィジェットで、今の状態と理由（どのアプリが止めているか）を確認できます
- Dock にもメニューバーにも出ません

## ダウンロード

[最新版の DMG](https://github.com/k-yoneda0614/awake-watch-releases/releases/latest) をダウンロードして開き、AwakeWatch を Applications にドラッグしてください。Apple の公証済みです。

## 最初に

Applications から AwakeWatch を開くと案内が出ます。

1. **補助デーモンを許可する**: システム設定 →「一般」→「ログイン項目と機能拡張」で AwakeWatch をオンにします
2. **通知を許可する**
3. （任意）コントロールセンターの編集から「フタを閉じても起きておく」を、デスクトップの「ウィジェットを編集」から「スリープの状態」を追加します

## 補助デーモンについて

「フタを閉じても起きておく」は macOS の `SleepDisabled` という設定で、変更に管理者権限が要ります。そのため小さな補助デーモンを管理者権限で動かします。

- できるのは `SleepDisabled` のオン・オフだけです
- 次のときは自分から元に戻します: AwakeWatch が 60 秒以上応答しない（無期限でも）/ 選んだ時間がたった / AwakeWatch 以外がオンにして 4 時間たった / 補助デーモンが再起動した
- ネットワーク通信はしません
- AwakeWatch 以外からの命令は、署名を確かめて拒否します

## アンインストール

1. AwakeWatch の詳細ウィンドウで「補助デーモンを削除」を押す
2. 「awake-watch を終了」を押し、Applications の AwakeWatch をゴミ箱に入れる
3. フタ閉じモードがオンのまま削除した場合は、ターミナルで `sudo pmset -a disablesleep 0` を実行する

アップデートは自動で確認されます。
